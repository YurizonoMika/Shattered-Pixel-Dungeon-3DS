# Floor mechanics parity

Reference: [Shattered Pixel Dungeon v4.0.2](https://github.com/00-Evan/shattered-pixel-dungeon/tree/v4.0.2), commit `57a4e06`. This is a rule-by-rule comparison for the floor subsystem, not a claim of seed parity.

| System | Reference entry points | Native implementation and remaining differences |
| --- | --- | --- |
| Initial population | `levels/RegularLevel.createMobs`, `actors/mobs/MobSpawner.getMobRotation` | Shuffled standard rooms, a consumed rotation, an eight-cell entrance exclusion, eight floor-one spawns, and a 25% second-monster attempt. Uses port LOS and generic room interiors. Missing specialized monsters, variants, champion rules, and class-specific room placement. |
| Respawn | `MobSpawner.act`, `levels/Level.spawnMob`, `RegularLevel.randomRespawnCell` | Out of sight in standard rooms, at least 12 steps away along a connected route, fractional dark cooldown, weighted population, and a one-turn retry. The current port has no endgame return climb, sundial, original actor scheduler, or independent per-floor save state. |
| Floor events | `levels/Level.create`, `Dungeon`, each regional NPC's `Quest` | Supported feelings each occupy one of fourteen outcomes; regular-floor rules do not spill onto bosses. Chasms, trinket overrides, original quest-room injection, Old Mine and Imp Vault are not equivalent. Corpse dust uses quadratic power costs but the port still uses a generic wraith and port FOV. |
| Rooms | `RegularLevel.initRooms`, `rooms/standard`, `rooms/special/SpecialRoom`, `rooms/secret/SecretRoom`, `levels/builders` | Entrances, exits and ordinary rooms use the original depth-based catalogs, size budgets and geometry constraints. Native `LoopBuilder` and `FigureEightBuilder` handle the graph. Special, secret, quest and shop inputs still use the port's run plan or simplified geometry. Layouts larger than 64×64 are retried; boss floors and exhausted retries use the legacy layout. Pit chains, remaining crystal rooms, and individual secret rooms are missing. |
| Terrain | `RegularPainter`, `Patch`, `Maze`, region painters | The cellular patch algorithm and five regions' water/grass parameters replace rectangular patches on regular floors. Native secret connectors use the upstream maze mask. Full room-specific terrain/placement rules, high grass, exact connector variants, and door/room merging rules are not yet synchronized. |
| Interactions and loot | `RegularLevel.createItems`, `randomDropCell`, `Dungeon.posNeeded`, `Dungeon.souNeeded`, `items/Generator`, room painters | Ordinary floor loot consumes alternating category decks across a run. Per-category item decks and artifacts are still missing. Iron, gold and crystal keys are separate on newly generated floors; there is no return climb or crystal-door interaction yet. Revealed traps remain active until triggered; floor one uses visible worn dart traps. Other trap types still use simplified effects. |

V10 saves retain actual map bounds and terrain, typed key counts, loot-deck state, and existing respawn state. V9 saves still load; their already-generated floors retain the shared key balance until descent. V9 files without spawn-room metadata cannot replenish ordinary monsters on the already-generated floor.

`bash tools/check-floor-layout.sh [path-to-upstream]` compiles the pinned v4.0.2 Java builders and terrain algorithms on the host. It compares 1,000 builder outputs with shared room descriptors, 500 patch masks and 100 maze masks. A separate oracle extracts the original room factories, budget methods and geometry methods and compares 2,000 ordinary-floor input lists (with the same initial RNG state, depth and Large flag), including room classes, size limits, sampled dimensions, door eligibility and final RNG state. This does not compare the incoming RNG state of a full game run, or the entire floor from the same run seed.

In Azahar, scene `87` checks 800 floors, including typed key budgets and stair reachability. v0.1.3alpha used `LoopBuilder` on 341 and `FigureEightBuilder` on 299 of the 640 normal floors, with no legacy fallback. Scene `91` checks respawn retry and rotation; `92` checks three locks, trap states and a V10 save round-trip. A full-floor comparison still needs original special, secret, shop and quest input rules, room painters, and terrain, entity and event fixtures.
