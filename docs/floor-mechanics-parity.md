# Floor mechanics parity

Reference: [Shattered Pixel Dungeon v4.0.2](https://github.com/00-Evan/shattered-pixel-dungeon/tree/v4.0.2), commit `57a4e06`. This is a rule-by-rule comparison for the floor subsystem, not a claim of seed parity.

| System | Reference entry points | Native implementation and remaining differences |
| --- | --- | --- |
| Initial population | `levels/RegularLevel.createMobs`, `actors/mobs/MobSpawner.getMobRotation` | Shuffled standard rooms, a consumed rotation, an eight-cell entrance exclusion, eight floor-one spawns, and a 25% second-monster attempt. Uses port LOS, fixed room interiors and the supported roster. Missing specialized monsters, variants, champion rules, and class-specific room placement. |
| Respawn | `MobSpawner.act`, `levels/Level.spawnMob`, `RegularLevel.randomRespawnCell` | Out of sight in standard rooms, at least 12 steps away along a connected route, fractional dark cooldown, weighted population, and a one-turn retry. The current port has no endgame return climb, sundial, original actor scheduler, or independent per-floor save state. |
| Floor events | `levels/Level.create`, `Dungeon`, each regional NPC's `Quest` | Supported feelings each occupy one of fourteen outcomes; regular-floor rules do not spill onto bosses. Chasms, trinket overrides, original quest-room injection, Old Mine and Imp Vault are not equivalent. Corpse dust uses quadratic power costs but the port still uses a generic wraith and port FOV. |
| Rooms | `RegularLevel.initRooms`, `rooms/special/SpecialRoom`, `rooms/secret/SecretRoom`, `levels/builders` | Alternating equipment and consumable room selection with a per-floor eligible list and mutually exclusive potion rooms. A scheduled lab consumes a special slot. Large floors start from maximum budgets. Secret counts distribute over eligible floors. Variable room sizes, pit chains, crystal-key exclusion, full room painters, and individual secret rooms are still missing. The five boss arenas and their scripted population remain ports-in-progress. |
| Interactions and loot | `RegularLevel.createItems`, `randomDropCell`, `Dungeon.posNeeded`, `Dungeon.souNeeded`, `items/Generator`, room painters | Normal floor loot is placed after initial monsters and traps; loose food and planned upgrade/strength supplies are guaranteed on the tested seeds. Supported puzzle rooms queue their corresponding potions. Still missing the full generator decks, item catalog, floor-scoped key types, exact trap/heap rules, and original room-specific interactions. No claim of an exact total for specific item types including all reward sources. |

New saves retain standard room bounds, the remaining spawn deck and the cooldown in an optional trailer after the V9 data. Existing V9 saves remain readable; the already-generated floor does not replenish normal monsters until descent because it has no reliable room classification.

Regression scenes: `87` generates 800 floors and checks native invariants; `91` checks respawn failure/retry and the next monster type when a reachable cell becomes available. Neither is an upstream same-seed comparison. Full parity requires matching the upstream RNG and room classes, then comparing generated terrain, entities, heaps and events against a v4.0.2 fixture exporter.
