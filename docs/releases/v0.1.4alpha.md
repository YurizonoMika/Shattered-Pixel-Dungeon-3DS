## 简体中文

- 移植 v4.0.2 的六种连接房地形，以及普通柱阵房、隔间房和圆墙房的内部绘制。深渊使用原版边缘图块，阻止步行但不挡视线；暂未实现坠落到下一层。
- 1,800 组单房用例在相同尺寸、门位和随机数输入下，地形与最终随机数状态均与原版 Java 一致。这不代表同一种子会生成相同的整层地图。
- 3DSX 在 Azahar 通过 800 层生成检查，以及钥匙、陷阱和含深渊地形的存读档测试；CIA 安装成功。现有存档仍可读取，打开新版本的存档前不建议降级。

## English

- Ported six v4.0.2 connector interiors and the Pillars, Segmented, and Circle Wall ordinary room painters. Chasms use upstream edge tiles and block movement without blocking sight. Falling to the next floor is not implemented yet.
- Matched terrain and final RNG state in 1,800 isolated room fixtures against the original Java painters with identical dimensions, doors, and RNG inputs. Whole-floor same-seed parity is not claimed.
- The 3DSX passed an 800-floor Azahar audit plus key, trap, and chasm save/load checks. The CIA installed successfully. Existing saves still load; downgrading after saving in the new build is not recommended.
