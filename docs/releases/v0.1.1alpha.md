## 简体中文

普通层生成器向原版 v4.0.2 同步：移植单环和双环构建器、各区域的水草斑块算法，以及暗房连接迷宫。铁钥匙、金钥匙和水晶钥匙各开对应的锁。新存档采用 V10，仍可读取 V9 存档。

- 对照 v4.0.2 Java 源码，1,000 组相同输入的房间布局、500 组斑块遮罩和 100 组迷宫遮罩均一致。
- 3DSX 在 Azahar 通过 800 层生成检查；CIA 安装成功。
- 房型抽选、各房型专用绘制、首领层和任务子地图仍在移植。同一种子暂不能复现原版整层地图。

## English

This preview brings regular-floor generation closer to v4.0.2 with the Loop and Figure Eight builders, regional water and grass patches, and maze connectors for secret rooms. Iron, golden, and crystal keys open different locks. The new V10 save format still loads V9 saves.

- Matched the v4.0.2 Java code on 1,000 shared-input room layouts, 500 patch masks, and 100 maze masks.
- The 3DSX passed an 800-floor audit in Azahar. The CIA installed successfully.
- Room selection, individual room painters, boss floors, and quest sublevels are still in progress. Whole floors do not yet match upstream from the same seed.
