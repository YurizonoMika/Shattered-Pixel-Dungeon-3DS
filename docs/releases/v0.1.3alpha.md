## 简体中文

普通层的入口、出口和普通房改用原版 v4.0.2 的五区房型权重、尺寸档位和几何约束。包括下水道前两层的选房限制、大型楼层的房间预算，以及圆形水池、巨型环形图书馆和下水管房的尺寸或门位限制。

- 在相同随机数初始状态、深度和大型楼层标记下，2,000 组房型抽选、尺寸和门位用例与原版 Java 一致。已有的 1,000 组布局、500 组斑块和 100 组迷宫对照继续通过。
- 3DSX 在 Azahar 通过 800 层检查；640 个普通层都没有回退到旧布局。CIA 安装成功，存档格式未变。
- 房间内部绘制、特殊房、暗房、商店和任务房的生成仍未完整移植；同一种子暂不能复现原版整层。

## English

Regular-floor entrances, exits, and ordinary rooms now use the v4.0.2 room weights, size categories, and geometry constraints across all five regions. This includes early Sewers restrictions, Large floor budgets, and size or doorway rules for circle basins, giant library rings, and sewer pipe rooms.

- Matched 2,000 upstream Java room-selection and geometry fixtures at the same initial RNG state, depth, and Large flag. The existing 1,000 layout, 500 patch, and 100 maze comparisons still pass.
- The 3DSX passed an 800-floor Azahar audit with no legacy fallback on any of the 640 regular floors. The CIA installed successfully. The save format is unchanged.
- Room interiors and the special, secret, shop, and quest room generation rules are still incomplete. Whole floors do not yet match upstream from the same seed.
