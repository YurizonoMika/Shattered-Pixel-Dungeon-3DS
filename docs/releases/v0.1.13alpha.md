## 简体中文

修复方向键短按、摇杆轻推时光标偶尔连续跳动多格的问题。

- 首次输入立即移动一格，持续按住 350 毫秒后开始连发，每 100 毫秒移动一格。
- 横纵轴独立计时，斜向输入变化不会再次触发另一轴。
- 摇杆使用 60/30 的触发/释放阈值防抖；单独读取十字键，避免系统合成的摇杆方向绕过防抖。
- 更新中英文 README 与内嵌截图。

输入测试覆盖短按、连发、独立轴、帧率变化、长帧和摇杆阈值抖动，并通过 ASan/UBSan。3DSX/CIA 构建验证通过。存档仍为 V12，兼容性与上一版本相同。完整机制对齐仍在进行，未进行真机手感测试。

## English

Fixes cursor movement skipping several cells after a brief D-pad press or Circle Pad nudge.

- Move once immediately; repeat starts after 350 ms, then moves once every 100 ms.
- Independent axis timers prevent diagonal changes from retriggering the other axis.
- Circle Pad activation/release hysteresis (60/30) suppresses threshold jitter. D-pad keys are read separately from synthesized Circle Pad directions.
- Refreshes both READMEs and embedded screenshots.

Input tests cover taps, repeats, independent axes, frame rates, stalls and analog jitter under ASan/UBSan. 3DSX/CIA builds passed. Save format remains V12 with unchanged compatibility. Full mechanics alignment remains in progress; hardware feel has not been tested.
