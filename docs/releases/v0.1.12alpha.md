## 简体中文

继续依据 pixeldungeon.wiki 的 Shattered 主命名空间和固定 v4.0.2 源码对齐机制。本版完成一批行动、装备、怪物和楼层状态改动；全游戏机制对齐仍在进行。

- 英雄和怪物按独立行动时间与优先级调度，移动速度与攻击速度分开。状态仍有共用时钟，尚未实现每个原版 Buff 的完整调度。
- 补齐 31 种普通近战武器的基础公式及 12 种戒指条目。增加已知/诅咒状态、诅咒装备更换限制、选择目标的鉴定/祛邪/升级，以及强化石的速度/伤害、闪避/防御选择。使用和经验推进基础鉴定；奥术之戒与神射之戒的附魔/投掷耐久效果仍未实现。
- 移植 Ballistica 弹道、ShadowCaster 视野和 Blob 毒气扩散；毒气按浓度扩散并按深度伤害，不再固定六回合消失。
- 加入部分怪物能力：远程法术与减益、蝎子后退、魔眼蓄力、死灵法师召唤/治疗、守卫锁链、武僧招架、蛮兵狂暴、蝙蝠吸血、骷髅爆炸、史莱姆减伤，以及史莱姆王蓄力和水中治疗。后续首领阶段、完整 AI/免疫/掉落等仍未完成。
- 支持上下楼和已访问楼层保存，第 26 层取得护符后可选择结束或返回地表；实现基础上行层数、怪物增幅、引敌、减速、伤害和首领层休整。
- 修正法杖逐次充能及其存档、掉落、回购和嬗变状态，背包满时保留地面物品与商店库存；修复暂停菜单选择。

存档升级至 **V12**，保存完整楼层实体、行动/AI/能力状态、装备标记/属性调整/鉴定进度、充能和毒气。导入 V9/V10/V11，缺失力量/饥饿为 10/0，旧装备视为已知且无诅咒。旧档未记录的历史楼层不能重建。旧版不能读取 V12；更新前备份 `sdmc:/3ds/spd/`。扩展档案采用本机值类型布局，不承诺不同平台交换存档。保存失败会保留原文件。

验证：实际游戏逻辑在隔离目录通过 ASan/UBSan 运行测试；961 组武器、465 组护甲强化、40,000 组弹道、10,000 组视野、17,500 步扩散与固定上游 Java 方法一致。已有房间/构建/寻路对照通过。Azahar 行动、装备、怪物、毒气、楼层、旧档及战斗回归通过；800 层检查零失败。CIA 安装启动成功，标题显示本版本，HOME 菜单名称和简介不含版本号；真实存档哈希未变。未进行真机测试；这些结果不代表完整同种子地图或全游戏一致。详见[机制复盘](https://github.com/YurizonoMika/Shattered-Pixel-Dungeon-3DS/blob/main/docs/wiki-mechanics-audit.md)。

## English

Continues alignment against the Wiki's Shattered namespace and pinned v4.0.2 source. This release adds actor, equipment, enemy and floor state mechanics. Whole-game parity remains incomplete.

- Individual actor clocks/priorities and separate movement/attack speeds. Buffs still share category clocks; complete independent buff scheduling remains.
- Base formulas for all 31 normally generated melee weapons and entries for all 12 rings. Persistent known/curse flags, equip locks, selected Identify/Remove Curse/Upgrade, augmentation choices and default use/XP identification. Arcana/enchantments and Sharpshooting/missile durability effects remain absent.
- Ports Ballistica, ShadowCaster and Blob diffusion. Toxic gas uses concentration and depth damage instead of a fixed six-turn lifetime.
- Selected enemy abilities: magic/debuffs, Scorpio retreat, Eye charge, necromancer summon/heal, guard chains, monk parry, brute rage, bat healing, skeleton explosion, slime reduction and Goo pumping/water healing. Later boss phases and full AI/immunities/loot remain incomplete.
- Remembered floors and upstairs, floor 26, Amulet completion or surface victory, and base ascent scaling/beckoning/slow/damage/boss rest.
- Persistent fractional wand recharge through saves, drops, shops and transmutation; full-bag purchases/pickups retain their source item. Fixes pause selection.

**V12** stores complete floor entities, actor/AI/ability state, equipment flags/augmentation/identification, recharge and gas. V9/V10/V11 import remains supported, with absent STR/hunger defaulting to 10/0 and old equipment known/uncursed. Missing historical floors cannot be reconstructed. Back up `sdmc:/3ds/spd/` before updating; older releases cannot load V12. Native value layouts are not a cross-platform interchange format. Failed saves preserve the previous file.

Validation: isolated runtime tests passed under ASan/UBSan. Pinned Java comparisons matched 961 weapon cases, 465 armor augmentation cases, 40,000 rays, 10,000 FOV masks and 17,500 diffusion steps. Existing builder/room/pathfinder comparisons passed. Azahar regressions passed actor, item, enemy, gas, floor, migration and combat checks; 800 floor checks had zero failures. CIA installed and booted with the correct title version and version-free HOME Menu metadata; real save hashes are unchanged. No hardware testing or whole-floor/whole-game parity is claimed. See the [mechanics audit](https://github.com/YurizonoMika/Shattered-Pixel-Dungeon-3DS/blob/main/docs/wiki-mechanics-audit.md).
